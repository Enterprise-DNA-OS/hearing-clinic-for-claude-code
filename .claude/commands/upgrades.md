Run `npm run clinic -- upgrades --json`. Show the eligible date and the funder, and whether anything is booked. Offer `/draft-upgrade` for each. Say plainly if it is empty. Never change a record from this command.

Ambiguous names list the candidates and stop: ask which one. Never send anything; drafts stay in `drafts/`.
